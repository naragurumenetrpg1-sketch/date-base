つぐも 事業管理ダッシュボード

自分のSNSアカウント（TikTok、Instagram）と事業の状況を、ひとつの画面で管理・分析するための、個人用ダッシュボードです。

できること

  • フォロワー数や投稿の再生数・いいね数などの推移を確認する
  • 売上・経費・入金の記録と、事業ごとの収支の確認
  • 日々のタスクと予定の管理

TikTokとの連携について

TikTokのログイン（Login Kit）と Display API を使い、運営者自身のアカウントの公開プロフィール情報とフォロワー数、投稿の一覧と各数値（再生数・いいね数・コメント数・シェア数）を読み取ります。読み取った情報は、運営者自身の分析にのみ使い、第三者には提供しません。
